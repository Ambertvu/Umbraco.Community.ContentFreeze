# Content Freeze for Umbraco Forms

[![NuGet](https://img.shields.io/nuget/vpre/Umbraco.Community.ContentFreeze.Forms?color=0273B3)](https://www.nuget.org/packages/Umbraco.Community.ContentFreeze.Forms)

Add-on for [Umbraco.Community.ContentFreeze](https://www.nuget.org/packages/Umbraco.Community.ContentFreeze). While a content freeze is active, Umbraco Forms changes in the backoffice are blocked too: forms and their workflows, folders, data sources and prevalue sources.

- Submissions from the website keep working.
- Save, create, move and delete actions are hidden during a freeze, and blocked on the server.
- Optionally also freeze working with entries (approve, reject, delete) and form permissions.

See the [documentation on GitHub](https://github.com/Ambertvu/Umbraco.Community.ContentFreeze#umbraco-forms) for settings.
